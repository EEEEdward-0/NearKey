# 蓝牙靠近解锁

Windows 11 上的本机应用。后台是原生 C++ 进程；设置界面是单独的 WPF 进程，关闭窗口后不驻留。登录组件沿用 `demo/credential-provider`，保留 Windows 原有 PIN 和密码登录入口。

## 已实现

- 扫描附近 BLE 广播，在设置界面选择最多 8 台设备。
- 只对最近 20 秒内检测到的已选设备计算 RSSI 均值；只检测到其中一台时按这一台计算。
- 设置解锁阈值、锁定阈值、离开持续时间，以及自动解锁和自动锁定开关。锁定阈值应低于解锁阈值，减少信号在边界波动时的反复操作。
- 后台通过本机命名管道向 Windows 登录组件提供状态；进入已登录账户的锁屏后，登录组件可自动提交已配置的本机密码。
- 手动锁定、登录后启动后台、状态查看和事件记录。事件日志达到 1 MB 后轮换到 `events.previous.log`。

## 当前本机验收状态

- 已验证：已安装的后台运行时，iPhone 在电脑附近，按 `Win + L` 后不点击或按键，电脑会自行返回桌面。用户在真实锁屏界面完成了验证。
- 已验证：普通用户和 SYSTEM 身份的登录组件探针都能取得接近状态；多设备均值、仅一台被检测到、信号过期等规则通过算法测试。设置界面已打开检查，并完成保存设置操作。
- 尚未实测：iPhone 移远后的自动锁定和界面“立即锁定”按钮。当前自动锁定保持关闭，待用户方便移远测试后再启用验收。
- 尚未验收：Apple Watch 的独立身份识别，以及长时间运行、手机锁屏和不同无线环境下的稳定性。

## 本机构建与安装

1. 安装 Visual Studio 2022 C++ Build Tools、Windows SDK 10.0.26100.0 和 .NET 10 SDK；运行 `app/build.ps1`。
2. 首次安装前，按 `demo/README.md` 在本机交互窗口配置 Windows 登录密码。不要把密码放在聊天、命令行或项目文件中。
3. 以管理员身份运行 `app/install-app.ps1`。它会安装登录组件和应用文件，并创建开始菜单“蓝牙靠近解锁”快捷方式。
4. 打开“蓝牙靠近解锁”，选择设备、调整规则并保存。设置会写到 `%LOCALAPPDATA%\BluetoothUnlock\settings.ini`；事件记录在同目录。

界面使用已安装的 .NET 10 Desktop Runtime，不把运行时打包进应用。停止或移除应用时，以管理员身份运行 `app/uninstall-app.ps1`；设置和事件记录会留在用户目录，便于用户自行决定是否删除。

## 设备身份与安全边界

- 已在这台电脑上验证 iPhone 的固定广播地址。某些设备（包括 Apple Watch）可能使用变化的私有地址；界面会显示匿名广播，但仅凭 Apple 厂商字段不能可靠确认哪条属于用户手表。未完成单独移远对照前，不应把匿名条目标成已验证的 Apple Watch。
- 蓝牙地址和 RSSI 可以伪造；它们不是强身份认证。启用自动解锁时，保存在本机受限注册表中的密码会由登录组件提交。离开后仍存在广播间隔和短暂信号保留时间。
- 只针对已经登录过的当前账户锁屏；开机首次登录仍由 Windows 原有方式完成。
