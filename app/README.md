# 蓝牙靠近解锁

Windows 11 上的本机应用。后台是原生 C++ 进程；设置界面是单独的 WPF 进程，关闭窗口后不驻留。登录组件沿用 `demo/credential-provider`，保留 Windows 原有 PIN 和密码登录入口。

## 已实现

- 扫描附近 BLE 广播，在设置界面选择最多 8 台设备。
- 只对最近 20 秒内检测到的已选设备计算 RSSI 均值；只检测到其中一台时按这一台计算。
- 设置解锁阈值、锁定阈值、离开持续时间，以及自动解锁和自动锁定开关。锁定阈值应低于解锁阈值，减少信号在边界波动时的反复操作。
- 解锁可选 A「仅蓝牙」、B「局域网设备在线」、C「蓝牙与局域网同时满足」。局域网用当前 iPhone IPv4 和 Wi-Fi MAC 匹配本地链路上的 ARP 应答；自动锁定仍使用原有蓝牙规则。
- 后台通过本机命名管道向 Windows 登录组件提供状态；进入已登录账户的锁屏后，登录组件可自动提交已配置的本机密码。
- 条件不满足时，登录组件不显示自己的磁贴，并在条件从满足变为不满足时通知 Windows 刷新，保留原生 PIN／密码入口。
- 手动锁定、登录后启动后台、状态查看和事件记录。事件日志达到 1 MB 后轮换到 `events.previous.log`。
- 后台 BLE 广播通过事件接收，每 2 秒汇总规则、每 4 秒写一次界面快照；界面每 4 秒读取一次。设备列表只显示最近 30 秒收到的广播，明确区分已选择设备与身份未确认设备，并按冒号分组显示 MAC。

## 当前本机验收状态

- 已验证：后台停止、没有接近信号时，用户在真实锁屏界面可直接使用 Windows 原有 PIN／密码登录，不再被应用磁贴的报错困住。
- 已验证：B 模式下刻意把蓝牙阈值调到无法满足，局域网条件独立满足；用户在真实锁屏界面确认无点击自动进入桌面。C 模式在蓝牙不满足时拒绝，在两项都满足时通过后台判断；C 尚未单独做锁屏验收。测试后已恢复 A 模式及原阈值。
- 已验证：最终安装版的 A 模式在 iPhone 靠近时，用户于真实锁屏界面确认无需点击即可进入桌面。此前曾有相互矛盾的反馈，因此长期稳定性仍待观察。
- 已验证：普通用户和 SYSTEM 身份的登录组件探针曾取得接近状态；多设备均值、仅一台被检测到、信号过期及 A/B/C 条件组合通过算法测试。安装版界面已打开检查。
- 尚未实测：iPhone 移远后的自动锁定和界面“立即锁定”按钮。运行中的自动锁定开关以设置界面为准；此次改动不自行更改其原有开关。
- 尚未验收：Apple Watch 的独立身份识别，以及长时间运行、手机锁屏和不同无线环境下的稳定性。
- Apple Watch 移远对照：iPhone 留在电脑旁，分别采集手表近距离约 24 秒、移远约 60 秒、返回约 36 秒的广播。扫描结果中多条匿名地址持续存在，返回后也出现新地址；这次对照未找到可唯一且稳定归属手表的蓝牙地址。因此当前不能将 Apple Watch 标为已支持的独立解锁设备。
- 用户随后提供了 Apple Watch“关于本机”页面的蓝牙地址；当前 BLE 扫描列表及连续约 30 秒复查均未出现该地址。设备页面上的蓝牙地址不能直接推定为 Windows 接收到的 BLE 广播地址。未验证地址可被扫描器持续观察到之前，不把它写入选中设备配置。

## 本机构建与安装

1. 安装 Visual Studio 2022 C++ Build Tools、Windows SDK 10.0.26100.0 和 .NET 10 SDK；运行 `app/build.ps1`。
2. 首次安装前，按 `demo/README.md` 在本机交互窗口配置 Windows 登录密码。不要把密码放在聊天、命令行或项目文件中。
3. 以管理员身份运行 `app/install-app.ps1`。它会安装登录组件和应用文件，并创建开始菜单“蓝牙靠近解锁”快捷方式。
4. 打开“蓝牙靠近解锁”，选择设备、调整规则并保存。设置会写到 `%LOCALAPPDATA%\BluetoothUnlock\settings.ini`；事件记录在同目录。

界面使用已安装的 .NET 10 Desktop Runtime，不把运行时打包进应用。停止或移除应用时，以管理员身份运行 `app/uninstall-app.ps1`；设置和事件记录会留在用户目录，便于用户自行决定是否删除。

## 设备身份与安全边界

- 已在这台电脑上验证 iPhone 的固定广播地址。某些设备（包括 Apple Watch）可能使用变化的私有地址；界面会显示匿名广播，但仅凭 Apple 厂商字段不能可靠确认哪条属于用户手表。移远对照仍未找出可稳定归属手表的地址，不应把匿名条目标成已验证的 Apple Watch。
- 蓝牙地址和 RSSI 可以伪造；它们不是强身份认证。启用自动解锁时，保存在本机受限注册表中的密码会由登录组件提交。离开后仍存在广播间隔和短暂信号保留时间。
- 局域网 IP/MAC 和 ARP 应答同样可以伪造。B 模式只说明设备在同一局域网，不能判断它是否靠近电脑；iPhone 休眠、切换网络、DHCP 地址变动或私人 Wi-Fi 地址变化都可能使 B/C 暂时失效。局域网配置只保存在当前用户目录，不写入项目源码。
- 只针对已经登录过的当前账户锁屏；开机首次登录仍由 Windows 原有方式完成。
